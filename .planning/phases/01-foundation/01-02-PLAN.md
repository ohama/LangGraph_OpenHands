2. `async def worker_loop(queue, graph, jobs_db_path)`:
   - Loop forever: `job_id, goal = await queue.get()`.
   - Create a per-job cancel `asyncio.Event` in `_cancel_flags[job_id]`.
   - Build `_get_job_logger(job_id)`; set status RESEARCHING; build `config = {"configurable": {"thread_id": job_id}}` (thread_id==job_id) and the full initial_state dict.
   - `async for chunk in graph.astream(initial_state, config=config, stream_mode="updates")`: if cancel event set -> set_status CANCELLED + break; else for each node_name in chunk map to next status. On "execute" complete, fetch final state via `graph.aget_state(config)` and `set_complete(job_id, result)`; else `set_status(job_id, next_status)`. Log each transition with the per-job logger (timestamped — handler format already includes asctime).
   - Handle `asyncio.CancelledError` (service shutdown): set status back to PENDING (so Phase 5 can re-enqueue) and re-raise. Handle generic Exception: `set_failed(job_id, str(exc))` + `logger.exception`. `finally`: pop cancel flag, `queue.task_done()`.
3. `_get_job_logger(job_id)` per Pattern 7: child logger `f"job.{job_id}"`, idempotent handler add, FileHandler at `logs/{job_id}.log`, formatter `%(asctime)s %(levelname)s %(message)s`, `propagate = False` (CRITICAL — avoids duplicate/leaked lines in uvicorn stdout), level DEBUG, `os.makedirs("logs", exist_ok=True)`.
4. `_cancel_flags: dict[str, asyncio.Event] = {}` and `def request_cancel(job_id) -> bool` (set the event if present; return whether a running job was signalled). This is imported by the DELETE route in 01-03.

Document the LangGraph mid-node checkpoint-consistency caveat in a module docstring: cancel takes effect AFTER the current astream chunk, so the checkpoint reflects the last COMPLETED node, never mid-node state.
