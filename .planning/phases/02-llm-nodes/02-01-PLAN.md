<critical_constraints>
- ORCH-05: base_url and model names MUST come from env (LITELLM_BASE_URL, RESEARCH_MODEL,
  PLAN_MODEL). NEVER hardcode "http://localhost:4000" or "qwen-122b" inside node bodies —
  resolve via make_llm(). api_key is the literal string "dummy".
- max_retries=0 on every ChatOpenAI instance (RESEARCH Anti-Pattern): retries amplify load
  on a wedged 122B. Let the job FAIL instead.
- streaming=False (RESEARCH key finding): LiteLLM 1.86.1 has NO 504 issue; non-streaming
  131s call succeeded. ainvoke() returns a complete AIMessage regardless.
- max_tokens bounded: research=2000, plan=1500 (RESEARCH Pitfall 5 — keep 122B from wedging).
  timeout=300.
- NEVER instantiate ChatOpenAI at module top-level (RESEARCH Pitfall 2): env vars are read
  before load_dotenv() runs. make_llm() is called inside node functions only.
- node_models MUST be initialized as {} (empty dict), never None (RESEARCH Pitfall 3 — the
  merge reducer does {**left, **right} and crashes on None).
- ORCH-04: node_models is bounded (max 3 entries, one per node). It is NOT an unbounded
  accumulator. Do not add any list-of-messages field.
</critical_constraints>
