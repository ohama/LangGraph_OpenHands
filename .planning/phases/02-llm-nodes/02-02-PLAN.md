       This is the Phase 2-scoped resume proof; full launchd auto-resume is Phase 5.
  9. ASSERT from the inline python output:
       - research_node was NOT re-called on resume (event_log still has exactly one research

       - node_models == {"research":"qwen-122b","plan":"qwen-122b"} (attribution recorded

       - plan is non-empty.
