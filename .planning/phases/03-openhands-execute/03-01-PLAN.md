(num_retries MUST stay ≤2 — RESEARCH Anti-Pattern: avoid wedge amplification.)
       - Agent(llm=llm, tools=[Tool(name=TerminalTool.name), Tool(name=FileEditorTool.name)]) — FinishTool/ThinkTool are default; do not remove.
       - Conversation(agent=agent, workspace=workspace_dir, persistence_dir=workspace_dir, max_iteration_per_run=max_iterations, stuck_detection=True, visualizer=None, delete_on_close=True).
       - send_message(task_prompt) where task_prompt is the concise goal+plan template from RESEARCH Pattern 2 (keep <400 words — RESEARCH Pitfall 3), then convo.run() (BLOCKING — caller wraps in to_thread; do NOT add asyncio here).
       - After run(): read final_status=convo.state.execution_status; events=list(convo.state.events) (read BEFORE close — RESEARCH Pitfall 7); iteration_count via _count_agent_iterations; execution_result via _extract_finish_message (fallback to f"Agent completed with status: {final_status.value}").
       - Status mapping (RESEARCH Pattern 4): FINISHED→"success"; ERROR→"partial"; STUCK→"partial"; else→"partial". Build the success/partial result dict (keys below) and assign it to `result`.
       - On except ConversationRunError as exc: set `result = {"execution_result": f"Execution failed: {exc.original_exception}", "execution_status":"failed", "iterations_used":0, "final_sdk_status":"error", "event_count":0}`. DO NOT return early from inside the except — fall through to the finally so the transcript is still written. (If `convo` exists and its state is reachable, you MAY best-effort populate `events = list(convo.state.events)` inside the except so a partial transcript is captured; if not reachable, leave events as None — the finally handles both.)
       - TRANSCRIPT-ON-ALL-PATHS (W1 — verify_phase3.sh and test_full_pipeline_to_done assert execution_transcript.jsonl EXISTS even when convo.run() raises): in a `finally` block, ALWAYS materialize transcript_path:
             if events is not None:
                 serialize_transcript(events, transcript_path)   # normal / partial-event case
             else:
                 transcript_path.write_text("", encoding="utf-8")  # exception-before-events: empty JSONL so the file always exists
         Then close: `if convo is not None: try: convo.close() except Exception: pass` (closes tmux/executors — RESEARCH Anti-Pattern: must close). serialize_transcript must run BEFORE convo.close() (events are read from convo.state earlier; transcript_path is a plain Path so writing it does not need the live convo).
       - Add "transcript_path": str(transcript_path) to the returned `result` dict (set it on BOTH the success/partial dict and the ConversationRunError dict so callers always get the path).
       - Return `result` (the function returns AFTER the finally runs, so the transcript is guaranteed on disk before run_openhands returns OR raises). Returned dict keys: execution_result, execution_status, iterations_used, final_sdk_status, event_count, transcript_path.

    4. _count_agent_iterations(events) -> int: sum 1 for ActionEvent with source=="agent" (RESEARCH Pattern 2). _extract_finish_message(events) -> str|None: reversed scan for ActionEvent with tool_name=="finish", return event.action.message if present (RESEARCH Pattern 2).

    5. serialize_transcript(events, output_path) -> None: mkdir parent; write each event.model_dump_json()+"\n"; if events is empty, write an empty file (still creates execution_transcript.jsonl); on per-event exception write a {"error":"serialization_failed","type":...} line instead of crashing (RESEARCH Pattern 2/6).

    Do NOT import asyncio, LangGraph, or OrchestratorState here — this module must be pure-SDK and synchronous so it can be stubbed out wholesale by 03-02's tests.
